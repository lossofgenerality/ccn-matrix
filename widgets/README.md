# CCN widgets (Stage 4)

This folder installs [matrix-org/matrix-widget-api](https://github.com/matrix-org/matrix-widget-api) 1.20.0, the library that lets a web page run inside a Matrix room and talk to it.

It is in place for Stage 4 of the roadmap: offering one CCN page, such as the CARTELS! comic or Laplacian Lab, as a room widget. No widget pages have been built yet.

To install: `npm install` in this folder.

Widgets work in Element (Web/Desktop). Other apps show them inconsistently, so a widget should add to the plain CCN page, never replace it.
